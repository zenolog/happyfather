# 멋진 가족을 위하여

모바일 HTML 게임입니다.

## 실행 방법

* `index.html` 파일을 브라우저에서 열면 바로 실행됩니다.
* GitHub Pages에 업로드하면 휴대폰으로 접속해서 플레이할 수 있습니다.

## 2026-11 조작 방식 변경

* 자동 이동이 사라졌습니다. 방향키를 한 번 누르면 한 칸 이동하며, 스와이프도 한 칸 이동합니다.
* 벽에서는 이동이 멈추고 게임오버가 발생하지 않습니다. 가족끼리 겹치거나 통과해도 게임오버는 없습니다.
* 가족 사이의 네모 연결 칸은 표시하지 않습니다. 모든 가족 캐릭터는 바로 앞 캐릭터의 직전 위치를 따라가며, 사이에 빈칸을 두지 않습니다.
* 게임판을 12×17칸에서 7×10칸으로 줄여 캐릭터가 더 크게 보입니다.
* 배경 그림은 잘라내지 않고 게임판 안에 전체가 들어가도록 표시합니다.
